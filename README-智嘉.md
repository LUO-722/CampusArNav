# 科文智嘉（CampusArNav）

江苏师范大学科文学院（潘安湖校区）的校园助手，Android 应用，包名 `com.campus.arnav`，Kotlin 编写。课程表、通知录活动、校园导航、对话问答集中在一个 App 里；课程、聊天、登录态都只存在本机，不登录也能用。

## 功能

### ① 课程表（默认页）

- 7 天 × 12 节自绘网格，周视图 / 日视图切换；节次号下标注每节开始时间（科文作息 8:15 起）。
- 工具栏：导入课表、＋课程、示例课表、导出 / 分享、＋活动、清空；课程与活动都支持编辑、删除。
- 活动直接画进网格；同一格既有课又有活动时，在课程块上挂「＋N 活动」角标，不遮课名。
- 导入支持文本（`课程|周几|起节|止节|周次|地点`，也认逗号、制表符）和 JSON 备份；导出可分享给微信或文件传输助手。
- 单周停课：某门课某周不上，只在那一周隐藏并标灰。

### ② 智嘉（通知录活动）

- 三种输入：粘贴通知文字、选通知截图、贴公众号 / 网页链接。
- 提取出的活动草稿可勾选、逐项修改（标题、日期、时间、地点、主办方、备注），确认后写入课表。
- 与已有课程冲突时三选一：都保留、只保留原安排、只录入新安排（后者把原课程当天标记停课）。
- 有网时整张图交内置看图模型理解（群聊截图、海报、通知都能认），断网用本机 OCR 兜底。

### ③ 导航

- 27 个目的地（23 栋楼 + 3 个校门 + 湖泊 / 广场）搜索，显示距南门距离与沿路步行时间。
- 底图为学院官方卫星实景影像，路线沿卫星影像上可见的校内道路计算，不是直线连线。
- AR 步行导航：摄像头实景叠加地面箭头，按手机朝向实时转向。
- 现场取点校准：到楼下可修正楼栋坐标；「开始测绘」沿路走一圈，轨迹并入本机路网。
- 「拉起地图」用系统 URI 打开本机地图 App 看真实路线，不依赖地图 SDK、不需要 Key。

### ④ 对话

- 本机知识库（108 篇、约 34.8 万字）优先回答；知识库覆盖不到或问题带时效性时联网检索，回答末尾标注来源。
- 可执行动作：加课、录活动、删活动、设闹钟、查课表、搜知识库、导航（写操作先弹确认）。
- 支持发图：有网交看图模型识别，断网用本机 OCR 把文字填进输入框。
- 聊天记录自动存档，顶部「记录」可回看历史会话、删除不需要的记录。

### ⑤ 我的

- 学籍卡（教务同步后显示姓名、学号、院系、专业、班级、宿舍，可编辑）。
- 学期与当前周、课程 / 本周 / 考试 / 成绩四格统计、本周课程按星期分组。
- 教务数据卡：同步教务、全部考试、全部成绩、教务原文；登录教务也在这里（可选的第六个入口）。
- 快捷入口：课程表、设置、导出课表、关于。

## 安装与升级

- 安装包：项目根目录 `科文智嘉-0.26.0.apk`（versionName 0.26.0 / versionCode 85，19.0 MB，只含 arm64-v8a）。
- 当前是 debug 签名，可直接覆盖 0.20 之后的版本升级，不必卸载；卸载会清掉本机课表、聊天与登录态（课表可以重新登录教务同步）。
- 构建产物：`app\build\outputs\apk\debug\app-debug.apk`。

## 首次使用

1. 安装后打开，直接落在「课程表」：第一次是 10 门示例课，课程块上有「示例」角标。
2. 想换成自己的课表：到「我的 → 教务数据 → 登录教务（可选）」，或点课程表顶部的「去登录」。
3. 不登录也能用：手动「＋课程」、批量导入、导出备份；示例课随时可以在工具栏「清空」。
4. 设置页「学期设置」按教务校历填学期开始日与总周数（默认 2026-09-07、19 周），课程表周次按它计算。
5. 想用课前提醒：允许通知权限，在设置页「提醒」里选提前 5 / 10 / 30 分钟。

## 教务登录（可选）

### 内网与外网

- 内网：`http://10.110.225.76/jsxsd/`，全天可登录、可同步，需要连校园网。
- 外网：`http://222.187.129.200:51234/jsxsd/`，学校开放时间约 9:00—18:00；校外也可以用学校 WebVPN 或移动 5G 校园专网访问内网。

### 登录后会做什么

- 自动抓取课表、考试、成绩与学籍信息，导入本地并替换示例课。
- 同步失败时保留本机原有课表，不会清空；「最近同步」时间只在真正成功时更新。
- 勾选「记住学号密码」时，密码用 AndroidKeyStore 中的密钥 AES/GCM 加密后保存，明文不落盘。

### 失败排查

- 先确认网络：内网要校园网，外网看是否在开放时段。
- 提示「学号或密码不正确」就核对账号；出现验证码时按图片输入，可换一张重试。
- 仍失败时到「设置 → 教务系统」重新登录；登录状态卡住可以先退出登录再登。
- 教务页面改版后需要更新 `JwxtClient` 里的路径与字段名。

## 校园导航

- 底图是学院官方卫星影像，坐标统一为 GCJ-02；楼栋与目的地点位按官方图逐楼量取。
- 路线不是直线连线，而是沿卫星影像上可见的校内道路计算（`assets/campus_roads.json`，745 节点 / 4443 条边，A* 加权），距离沿路累加。
- 官方导览图与卫星图上的叫法不完全一样（图书馆 = 明志楼、行政楼 = 崇德楼……），楼名与别名对照见 [地图对照表.md](地图对照表.md)。
- 定位优先 GPS，静止时用磁力计判断朝向；没有定位权限时以南门为起点。
- 「拉起地图」通过系统 URI 打开本机地图 App 看真实路线，不依赖任何地图 SDK，也不需要 Key。

## 数据与隐私

- 课程、活动、聊天记录、登录态只保存在本机（SharedPreferences + SQLite），不会自动上传。
- 教务密码加密保存；身份证号、家庭住址等敏感字段不落库、不显示。
- 发图时：有网会把图片交内置看图模型识别，仅用于本次处理、不保存；断网用手机本机 ML Kit OCR，图片不出手机。
- 云端问答走内置通道，学生不需要填任何 Key、接口地址或代理。

## 已知限制

- 路网与楼栋坐标按官方图测绘，尚未逐段实地验证，导航结果以现场路牌为准。
- 离线可用：课程表、活动、知识库问答、本机 OCR；联网问答与看图识别需要网络。
- 公众号文章直抓常被微信反爬，优先用截图或粘贴正文。
- 闹钟通过系统时钟应用创建，需要在闹钟列表里确认保存。
- 课前提醒受系统省电策略影响，部分机型需要把 App 加入自启动 / 后台白名单。
- 只打包了 arm64-v8a 一份 native 库，x86 模拟器无法安装。

## 常见问题

**打开是示例课表，不是我的课？** 说明还没登录教务，课程块上的「示例」角标就是这个意思；登录并同步后会自动替换，或手动加课、导入课表。

**登录成功了课表没变？** 到「我的 → 教务数据」看最近同步时间；同步失败时本机原课表会被保留，可以过一会儿重试或换内网 / 外网。

**聊天记录在哪？** 对话页顶部的「记录」；每次打开 App 都是新对话，旧对话自动收进记录。

**没有网络还能用哪些功能？** 课程表、活动、知识库问答、本机 OCR 都能用；联网问答、看图识图和教务同步需要网络。

**导航准不准？** 楼栋点位按官方图量取，路网按卫星影像测绘，够用于校内找路；正式使用前建议在「导航 → 楼栋取点校准」按现场微调一次。

## 开发

代码在 `app/src/main/java/com/campus/arnav/`，按职责分目录：

- `ui/`：五个页面与自绘控件（课程表网格、校园地图、对话、我的）
- `core/`：地图投影、路网算路、提醒、坐标转换
- `data/`：课表、活动、聊天、教务缓存、设置（SQLite / SharedPreferences）
- `agent/`：对话编排与动作执行；`net/`：模型与教务请求；`ocr/`：本机识字；`kb/`：知识库检索；`debug/`：离线自检
- 入口 `MainShellActivity`，启动配置在 `AndroidManifest.xml`

构建（本机依赖已缓存，必须离线）：

```powershell
$env:JAVA_HOME='E:\Android\AndroidStudio\android-studio\jbr'
$env:ANDROID_HOME='E:\Android\Sdk'
$env:GRADLE_USER_HOME='E:\Android\gradle-home'
.\gradlew.bat assembleDebug --offline
```

- 产物：`app\build\outputs\apk\debug\app-debug.apk`
- 签名：日常用 debug 签名；正式包需要项目根目录的 `keystore.properties` 与 `zhijia-release.jks`（都已进 `.gitignore`，不入库），`assembleRelease` 会自动给 release 包签名。
- 云端 Key 写在 `local.properties` 的 `dashscope.*`（已忽略），构建时以 `buildConfigField` 注入，仓库里搜不到 Key。
