# 科文智嘉（CampusArNav 四栏版）0.2.9

在原有 AR 校园导航 APK 雏形上增加的四栏「智嘉」校园助手。包名仍是 `com.campus.arnav`，可直接覆盖安装旧 debug 包。

## 安装包

- `E:\AndroidProjects\CampusArNav\科文智嘉-debug.apk`（4,752,919 字节，debug 签名，versionName 0.2.9）
- 构建产物：`app\build\outputs\apk\debug\app-debug.apk`

## 本版（0.2.9）改进

- Agent 写操作先确认：模型决定加课、录活动、设闹钟、删课、删活动时，先弹“允许智嘉执行这些操作？”并列出动作摘要；点「允许」才写库/开闹钟，点「取消」不执行。
- 查询类动作（查课表、搜知识库、导航）仍然即时执行，不打断问答。
- 取消后聊天区会记录“已取消执行”，能看到这次没有落库。
- 离线自检新增「动作确认文案」，确保确认框里能读懂每个动作。

## 本版（0.2.8）改进

- Agent 录活动去重：同一活动名 + 同日期 + 同开始时间已存在时返回“未重复录入”，不会因为多问一次就多出一条。
- Agent 查课表不再显示已停课课程：`list_schedule` 现在会排除当天的停课记录，和课程表页面口径一致。
- 识图配置提示修正：发图只需要通义 VL 的 Key，不再要求先切换聊天模型。
- 离线自检新增「节次定位」：08:00→第 1 节、09:30 课间→第 3 节、10:30→第 4 节、23:00→第 12 节。

## 本版（0.2.7）改进

- 智嘉活动草稿编辑时立即校验：日期必须是合法 `yyyy-MM-dd`、时间必须是 `HH:mm`、结束必须晚于开始，不合法当场提示，不再等到点「录入」才被跳过。
- 时间统一补零：`9:00` 会存成 `09:00`，重复判断、冲突判断和展示都用同一格式，避免“看起来同一个活动被判成两条”。
- 提取按钮防连点：提取中按钮禁用并显示「提取中…」，再点提示“正在提取，请稍等”，不会并发起多个模型请求。
- 冲突三选一逻辑复核：都保留（标记冲突）、只保留原安排（丢弃新活动）、只录入新安排（把原课程当天标停课）行为一致。

## 本版（0.2.6）改进

- 离线自检新增两项：**周次边界**（第 1/16 周命中、第 0/17 周不命中、最后一周日期回算正确）与**冲突判断**（时间重叠能命中、无重叠不命中、已停课不命中）。
- 课程表网格补充无障碍描述（读屏会读出“课程表：7 天 × 12 节；点课程块查看详情”）。

## 本版（0.2.5）改进

- 课程表新增「导出 / 分享」：把当前课表导出为 JSON（含学期名、开始日、总周数、每门课的教师/地点/周几/节次/周次），经系统分享面板发给微信/文件传输助手/邮件，或复制后粘贴回「导入课表 → JSON」，方便换机与备份。
- 课程表操作区改成两行按钮，窄屏下「导入/＋课程/示例」与「导出/清空」不再挤成多行或截断文字。

## 本版（0.2.4）改进

- 对话页新增「图」按钮：选一张通知截图发给通义 VL，让它在聊天里直接识图回答/提取活动（图片先压到最长边 1600px）。识图会走通义 VL Key，文本问答仍按模型标签选择。
- 识图提问会把图片与当前输入的文字合成一条多模态消息；输入为空时默认问“识别通知里的活动信息”。
- 图片发送前检查通义 VL 是否已配置，未配置直接提示去设置。

## 本版（0.2.3）改进

- Agent 新增「删除活动」动作：可以说“删掉 9 月 25 日的迎新晚会”，按活动名（支持包含匹配）和可选日期删除。
- 录活动失败时给出可操作提示：日期无法识别会明确回报“应为 yyyy-MM-dd”，不再静默按今天处理。
- 日期/时间归一化更严格：拒绝 13 月、32 日这类非法日期；识别下午/晚上/中午/凌晨与“半”的同时，不再把“第3点要求”误判成 03:00。
- 测试连接改为先保存当前输入框的 Key 再测试，避免“刚填完 Key 点测试仍报未配置”。
- 导航坐标显示固定用点号小数（不受系统地区格式影响）；聊天模型文案明确为“文本问答”，不暗示聊天可直接发图。

## 本版（0.2.2）改进

## 首次使用

1. 安装 APK，打开「科文智嘉」。
2. 进入「对话」页，点左上角 `☰`（或模型标签 → 打开设置）。
3. 填 DeepSeek：`https://api.deepseek.com` / `deepseek-chat` / 你的 Key。
4. 要识图再填通义 VL：`https://dashscope.aliyuncs.com/compatible-mode/v1` / `qwen-vl-max-latest` / 你的 Key。
5. 保存；回到对话页点模型标签可切换聊天模型。Key 只存本机 SharedPreferences。
6. 设置页「学期设置」按教务校历填开始日（当前默认 2026-09-07、19 周），课程表周次会按它计算。

## 构建

```powershell
$env:JAVA_HOME='E:\Android\AndroidStudio\android-studio\jbr'
$env:ANDROID_HOME='E:\Android\Sdk'
$env:GRADLE_USER_HOME='E:\Android\gradle-home'
& 'E:\AndroidProjects\CampusArNav\gradlew.bat' -p 'E:\AndroidProjects\CampusArNav' assembleDebug --offline
```

本机 Gradle 依赖已缓存，必须加 `--offline`。

## 数据与限制

- 知识库是构建时打包的快照（`app\src\main\assets\kb.json`），知识库更新后需重新生成并打包。
- 楼栋坐标除老工程自带估算值外，新增 6 个目的地为按官方平面图推算，未实地打点；可在「导航 → 楼栋取点校准」现场覆盖。
- 公众号文章直抓会被微信反爬拦截，优先用截图或粘贴正文。
- 闹钟通过系统 `AlarmClock` Intent 调起，需用户在时钟应用里确认保存。
- 高德走 URI 跳转，不依赖高德 SDK Key；手机未装高德时用浏览器打开。
- 当前环境未连接 Android 设备，未做真机运行验证；已通过 `assembleDebug` 编译并检查 APK 清单/资源/知识库打包。离线 lint 因缺 lint-gradle 依赖未运行。
