# 科文智嘉（CampusArNav 五栏版）0.16.0

在原有 AR 校园导航 APK 雏形上增加的五栏「智嘉」校园助手。包名仍是 `com.campus.arnav`，可直接覆盖安装旧 debug 包。

## 安装包

- `E:\AndroidProjects\CampusArNav\科文智嘉-debug.apk`（debug 签名；versionName / versionCode 以 `app/build.gradle` 为准，当前 0.17.2 / versionCode 44；体积 48,159,559 字节（≈44.7 MiB），包含 ML Kit 中文 OCR 模型与内置地图 SDK（只留 arm64 一份 so））
- 构建产物：`app\build\outputs\apk\debug\app-debug.apk`

## 本版（0.17.0 开发中）改进：地图复刻官方底图

导航底图从「示意画」换成**直接复刻学院官方导览图**：

- **四张官方底图入包**（`app/src/main/res/drawable-nodpi/`）：卫星正射图（导航默认底图，位置最准）、平面导览图（楼名最直观）、编号图例（编号 ↔ 楼名对照）、交通导览图（环线/校门/停车场）。每张图的用途、编号与楼名对应关系见根目录 **`地图对照表.md`**。
- **投影改成控制点单应校正**：平面导览图与交通导览图是 3/4 透视，不能按经纬度线性贴图，必须选 3–4 个固定物控制点做单应（homography）变换后再叠路线；卫星正射图南北向、近似线性，仍用控制点微调（目标误差 < 1 个屏幕像素 / 10 米）。
- **楼名标签对齐官图**：标签位置与字面按官方图例（崇德楼/明志楼/风华楼/…/思齐广场），并补别名搜索——图书馆 = 明志楼、行政楼 = 崇德楼、大学生活动中心 = 风华楼、日月广场 = 思齐广场；教学楼 1/2/3/5 与实验楼/双创楼的对应为按位置推定，已在 `地图对照表.md` 中标「待现场核对」。
- **体积与加载**：JPEG 底图按长边 2048 缩放后内存解码，缩放/拖动时只重绘可见区域；底图随 APK 打包，离线可用。
- 界面与文案**不出现外部地图服务名称**；路线跳转走系统 URI（拉起本机地图 App，未安装时用浏览器打开）。
- 底部常驻注：**「数据为示意图，实际以现场为准」**。

> 底图为学院官方导览图/用户提供，仅用于校内导航示意；对外截图请保留「示意图」字样。

## 本版（0.16.0）改进：导航换成「离线 2D 地图 + 真路网算路」

导航页（第 3 栏）整个重做，AR 从主视图降级为可选入口：

- **离线 2D 地图**（`ui/CampusMapView.kt`，纯 Canvas、离线可用）：0.16 版底图是按经纬度线性贴图的示意图（0.17 已换成官方底图 + 控制点校正，见上一节），路线白边红芯（accent `#E8447A`），蓝点为当前位置 + 朝向扇形，双指缩放 0.6–4×、单指拖动、双击放大、点楼栋直接算路；`onDraw` 零对象分配。
- **离线校园路网 + A\* 算路**（`assets/campus_graph.json` + `core/CampusGraph.kt` + `core/CampusPath.kt`）：89 个节点（路口 38 / 楼体 23 / 楼门口 23 / 校门 3 / 湖面 2）、97 条边，边长按经纬度实时算；A* 启发式用 haversine。
  - 实测：南门→明志楼 **319 米 / 3 步**、→格物楼 529 米、→致广楼 594 米、→尚美书院 1025 米、尚美书院→体育馆 1451 米；校外 600 米处返回 null（不吸附）。
  - 步数文案参照主流导航 App 的写法：「沿中轴路向北直行 251 米」→「在明志楼南路口继续沿校园步道向北步行 68 米」→「到达明志楼（南门）」。
- **GPS 优先定位**（`core/UserLocator.kt`）：GPS + NETWORK 双源、1s/3m、精度>100m 丢弃、2s 内跳>200m 判漂移；朝向优先 GPS 航向，静止才用磁力计，都不行就不画箭头（不再瞎指）。点「定位」会申请权限，没权限就退回「南门」当起点。
- 导航页交互：顶部地图 + 「起点：南门 / 我的位置」切换 + 「定位」「清除」；点楼栋或列表项即算路，卡片显示距离/步行时间/前三步 + 「跟随」「AR」「拉起地图」三个按钮；「更多」里保留罗盘自检、楼栋取点校准与路线说明。
- **内置地图 SDK 已接入但未启用**（`com.amap.api:3dmap:10.0.600`，Key 从 `local.properties` 的 `amap.key` 注入，空 Key 时 `core/AmapEnv.kt` 的 `ready()` 返回 false，代码不创建 MapView）。拿到 Key 后只需在 `local.properties` 加一行，无需改源码。
- 体积：`ndk.abiFilters 'arm64-v8a'`（地图 SDK 的 so 双 ABI 占 33MB，本机 arm64，去掉 v7a），APK 从 90.9MB 降到 **46.9MB**。

> 路线是示意数据：路口按官方平面导览图方位估算、楼门口按「楼心朝最近路口偏移 20 米」生成，坐标精度约 ±100 米；地图用于找方向，走到楼附近以门牌路牌为准。

## 本版（0.15.0）改进：修好「提取不了文字」

- **根因**：`agent/NoticeExtractor.kt` 里文字提取仍在用 0.11.0 就废弃的 `SettingsStore.deepseek(ctx)`，内置 Key 不在那条通道上 → 必然抛异常 → 被静默回落到本机规则 → 用户只看到「本机没认出时间地点」。已改为内置云端通道 `chatProvider(ctx)`。
- **本机规则也补强了**：`agent/OfflineExtractor.kt` 新增「整句一行」的识别（`…16:30博学楼102教室` 这种，日期/时间/地点全在同一行）、书名号标题兜底、`通知一：` 前缀清理、去掉裸「场」误判（原来会把「市场调查」当成地点）。
- **失败不再静默**：状态行区分「云端没读出来：<原因>；已用本机规则重试」「看完了，这段内容里没有需要到场/报名的活动」「本机规则也没认出…」，并给一个「重试」按钮；智嘉页首屏/空态有常驻提示卡，不再是一片空白。
- **多了一个入口**：空态卡里有「去课程表手动加」，不用再自己找。
- **旧配置自动清理**：升级安装的用户如果旧版存过代理地址/DeepSeek Key，现在会在首次请求前一次性清掉（`SettingsStore.clearLegacy`），避免请求被改道到已失效的地址。
- **界面彻底去 API 化**：删掉「填 Key / 显示 Key / 接口地址 / 自备代理」的全部入口与死代码；模型选择弹窗改为只读提示「云端模型随网络自动切换，无需配置」。
- **对比度**：`text_secondary` 3.03:1 → 5.22:1，新增 `accent_ink #A61E46` 用于「当文字用的玫粉」（30 处），底栏选中字、示例角标文字、课表小字统一加深。
- 自检加到 31 条：新增「活动文字解析」（用真实三条通知断言能抽到 2026-11-26 / 15:30-16:30 / 博学楼）、「内置通道就绪」、「旧通道已废弃」。

## 本版（0.14.0）改进

- **智嘉选图改成「看懂图」，不再是先识字再猜**：以前是手机本机 ML Kit 认出文字、再交给文本模型/规则抽活动，艺术字、断行、错别字（截图里「防艾」被识别成「茄艾」）就废了。现在有网时把整张图交给百炼看图模型 `qwen3-vl-plus`，让它像人一样理解这张图：判断是群聊截图/海报/通知，按上下文纠正错字，再抽出活动。
- 看图模型单独一条通道：只用能看图的模型（文本模型收到图片会 400），接入时带 `response_format=json_object`、温度 0.1，失败自动换模型。
- 提示词里加了「校内地名归一」清单（思齐广场、方湖、星垂湖、韶光园、风华楼、明志楼、致广楼、笃行楼、格物楼、博学楼、弘毅楼、精工楼、匠心楼、一食堂、二食堂、商业街、校医院、体育馆、体育场、工程训练中心），图上是错字/近音也归到规范名；地点人名看不清就留空不猜；`organizer` 只认图里明确的「主办/承办/协办」，群昵称不算。
- 每项草稿多带一条「图上原文」片段，方便你核对模型有没有看错；`is_event=false` 时直接提示这张图里没看出活动。

## 本版（0.12.1）改进
：课程与活动重叠不再叠在一起

- 多门课同时重叠同一个活动时，角标按课程各挂一个，数字是该活动数（同格多条时显示 ＋2、＋3）。

## 本版（0.12.0）改进
：知识库没有就去网上查

- 接通百炼服务端的**联网搜索**（`enable_search` + `search_options.forced_search`）：模型自己搜、自己引用来源，
  App 端不额外访问任何网站，也不需要第二个搜索 Key。
- 什么时候联网（`AgentEngine.shouldSearch`）：
  - 本机知识库没命中，或最相关一条的得分低于阈值（说明知识库覆盖不到）；
  - 或者问的是时效性问题（今天/最近/最新/新闻/通知/公告/放假/活动/比赛/讲座/天气/本周/几号/几点…）。
