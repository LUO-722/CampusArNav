# 科文智嘉（CampusArNav 五栏版）0.9.0

在原有 AR 校园导航 APK 雏形上增加的五栏「智嘉」校园助手。包名仍是 `com.campus.arnav`，可直接覆盖安装旧 debug 包。

## 安装包

- `E:\AndroidProjects\CampusArNav\科文智嘉-debug.apk`（48,956,942 字节 ≈ 46.7 MB，debug 签名，versionName 0.9.0；体积主要来自随包打包的 ML Kit 中文 OCR 模型，换来断网可用）
- 构建产物：`app\build\outputs\apk\debug\app-debug.apk`

## 首次使用

1. 安装 APK，打开「科文智嘉」，先到**登录页**：填学号 + 密码 → 选内网/外网 → 勾「记住学号密码」→「登录并同步」（连不上校园网就点「先离线使用」，功能全在，只是不同步教务数据）。
2. 没同步过就用演示课表；同步过的课程会在课程表里替换掉旧的教务课程。
3. 进入「对话」页，点左上角 `☰`（或模型标签 → 打开设置）。
4. 填 DeepSeek：`https://api.deepseek.com` / `deepseek-chat` / 你的 Key；保存后回到对话页点模型标签可切换模型。Key 只存本机 SharedPreferences。
5. 识图不需要 Key：智嘉/对话里选图会走手机本机 ML Kit 中文 OCR，图片不上传。
6. 设置页「学期设置」按教务校历填开始日（当前默认 2026-09-07、19 周），课程表周次会按它计算；「教务系统」卡可立即同步/重新登录/退出登录。
